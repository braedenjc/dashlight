=========
Dashlight
=========

   Dashlight is a Python project that is inspired by the dashboard of a car, making it easy to see your Linux computer's health.

====
Goal
====

The idea behind it is to make it easy to see the health of your Linux computer
at a glance through the command line or a web browser by exposing
your computers state through /proc, /sys, and future additional inputs.

====
Why?
====

Linux has a lot of great ways to track a particular computer's status, but not a lot of it allows you to see if something
needs your attention in a simple manner. You usually need an infrastructure geared more toward server solutions, like a Mail Transfer Agent to send you an alert.

Since not all of us want to handle that level of configuration and maintenance, I decided to make this project and make something simpler, but easier
for an end user to configure and more readable for an end user to, at a glance, see if everything is okay on their computer.
